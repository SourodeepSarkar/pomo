# pomo v1
![Platform](https://img.shields.io/badge/platform-macOS%2014%2B-black?style=for-the-badge&logo=apple) ![SwiftUI](https://img.shields.io/badge/Built%20With-SwiftUI-orange?style=for-the-badge&logo=swift)

A minimal native Pomodoro timer for macOS focused on frictionless deep work, clean interaction design, and local-first session tracking.

Built entirely with SwiftUI and designed to feel lightweight, calm, and fast.

---

## Highlights

### Focus Timer System
- Classic Pomodoro workflows
- 25/5 and 50/10 presets
- Manual time adjustment controls
- Full pause, resume, reset support
- Automatic focus/break transitions

### Intelligent Session Flow
- End-of-session decision overlay
- Continue studying or begin break instantly
- Native actionable macOS notifications
- Break completion prompts
- Smooth uninterrupted workflow handling

### Session Tracking
- Automatic focus session persistence
- Effective duration calculation
- Pause-aware tracking system
- Historical session timeline
- Weekly focus hour analytics

### Sessions Dashboard
- Dedicated Sessions window
- Daily session filtering
- Weekly productivity overview
- Relative date organization
- Session deletion controls

### Native macOS Experience
- Fully native SwiftUI interface
- Apple-inspired minimal aesthetic
- Adaptive dark/light mode support
- Smooth animations and hover interactions
- Glassmorphism-based UI components

### Menu Bar Integration
- Persistent menu bar timer
- Quick playback controls
- Instant timer visibility
- Lightweight floating interaction model

### System Integration
- Sleep prevention during active focus sessions
- Native notification support
- Fullscreen optimized workflow
- Multi-window support

### Sparkle Integration
- In-app update delivery via Sparkle
- GitHub-based update distribution
- Seamless update checks

## Privacy

pomo is fully local-first.

No telemetry.
No analytics collection.
No accounts.
No cloud dependency.

All session data remains on-device.

---

## Requirements

- macOS 14+
- Notification permissions recommended for session actions

---

## Known Limitations

Because pomo is currently distributed without Apple Developer notarization:

- macOS Gatekeeper warnings may appear
- First launch may require:
  Right Click → Open

This does not affect functionality.

---

## Installation

1. Download `pomo.zip`
2. Extract the archive
3. Move `pomo.app` into Applications
4. Launch pomo
5. Grant notification permissions when prompted
